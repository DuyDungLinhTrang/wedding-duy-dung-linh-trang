# Thiệp cưới Dũng & Linh Trang

Mở `index.html` để xem thiệp. Thư mục này đã sẵn sàng để đưa lên GitHub Pages.

## Xuất bản nhanh

1. Tạo một repository mới trên GitHub.
2. Tải toàn bộ nội dung thư mục này lên repository.
3. Vào **Settings → Pages**, chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)`.
